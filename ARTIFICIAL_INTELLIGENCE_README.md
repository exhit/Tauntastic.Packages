Package "com.tauntastic.packages" (Editor-only assembly and namespace Tauntastic.Packages.Editor, no dependencies): update notifications for Tauntastic packages installed from a GitHub git URL, which the Package Manager does not provide. It works on its own once imported, so do not write code to start it: on Editor start (at most once per interval, default 24 hours, skipped in batch mode and when offline) PackageUpdateChecker lists the registered packages whose name starts with "com.tauntastic." and whose source is Git, parses each package id with GitPackageReference.TryParse (GitHub HTTPS only; supports ?path= sub folders; a commit hash or version tag ref means follow the default branch HEAD, any other ref is a branch), downloads raw.githubusercontent.com/<owner>/<repo>/<branch>/package.json with UnityWebRequest, and compares its "version" with the installed one using PackageVersion.IsNewer(candidate, current) (major.minor.patch with optional pre-release tag; a release is newer than its pre-release). When updates exist it logs a warning per package with the changelog URL and opens the PackageUpdateWindow once per distinct set of updates. Menus (kept first in Tools > Tauntastic by negative MenuItem priorities in PackageMenuPriority, and this package is also sorted first in the results list): Tools > Tauntastic > Packages > Updates (window with Check now, Update, Changelog and Repository buttons) and Check For Updates (forced, always reports). Settings are per-user EditorPrefs under Preferences > Tools > Tauntastic > Packages (PackageUpdateSettings: Enabled, IntervalHours, OpenWindowOnUpdate). From code use PackageUpdateChecker.CheckNow(bool userInitiated), the read-only Results (PackageUpdateInfo with Name, DisplayName, InstalledVersion, LatestVersion, Status Checking, UpToDate, UpdateAvailable or Failed, Error, Reference) and the Changed event, and PackageUpdateChecker.Update(info) which calls Client.Add with the branch URL (this unpins commit hashes and tags). For updates to be detected, a package repository must raise "version" in its package.json when releasing, and only public GitHub repositories work because no credentials are sent. Packages stored inside Assets or Packages folders, registry packages and non-GitHub hosts are ignored. Never reference these Editor types from runtime code, and do not poll faster than the interval to avoid hitting GitHub rate limits.
